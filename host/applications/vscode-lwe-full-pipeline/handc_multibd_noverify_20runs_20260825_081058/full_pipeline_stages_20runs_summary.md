## 口径说明

- `online_e2e_ms`：从 SSD->SLM 开始，到目标 SSD 写入并回读校验完成。
- `one_shot_e2e_ms`：在 online 口径上增加最初的 encrypt SLM 创建。
- `rpc_round_trip_ms` 已包含请求发送、远端处理和响应接收，不能与其子阶段重复相加。
- `remote_server_total_ms` 已包含远端 request receive、HPU、编码和 response send。
- `wait_response_header_ms` 与远端接收/处理并行重叠，不是独立可加阶段。
