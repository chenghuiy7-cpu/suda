# 第三章 System Overview：中文读稿

FHEStore 通过两条存储侧路径连接持久化应用数据与外部 FHE 计算服务：输入路径执行预处理、编码与加密，返回路径执行解密、解码与结果写回。Host 通过算子程序协调这些路径，并在 CSD 与远端服务之间转发密文批次。

## 3.1 系统组成

总体架构包含 FPGA 计算存储设备（CSD）、Host 和远端 FHE 服务三个部分。CSD 集成持久化存储、设备本地缓冲、Device Runtime 和 FPGA 算子。输入路径从存储读取数据，经可选的预处理后交给编码与加密算子；返回路径将结果密文交给解密与解码算子，再把恢复的应用值交给写回操作。

Host 承担任务控制与密文转发两项工作。Task Runtime 将应用请求转换为算子图、逐算子上下文和数据范围，供设备执行。密文转发模块从 CSD 获取输入密文并发送给远端服务，再将返回密文送入 CSD 的解密路径。Host 与 CSD 通过 PCIe 连接，任务控制与密文传输均经过这一连接。Host 与远端服务通过网络通信，当前原型使用 TCP；远端 HPU 对接收到的密文执行同态计算。

Host 与 CSD 位于数据所有者的可信处理域内，因为预处理、解密与记录合并需要访问明文。Host 通过算子上下文向本地密码算子提供秘密密钥材料。远端服务使用对应的评估密钥处理密文。

## 3.2 应用任务模型

应用任务表示为 $T=(D,Q,E,O)$。$D$ 描述源数据，包括存储命名空间、块范围、记录数和字段布局；$Q$ 描述筛选条件与投影字段；$E$ 指定编码方式、密码参数和本地密钥引用；$O$ 指定下游动作，即交付生成的密文，或继续执行远端计算并将恢复结果写入指定位置。

对于记录输入，字段布局给出记录宽度、字段类型与字节偏移。当前选择性处理原型支持对整数字段进行条件比较，并将一个 unsigned 8-bit 字段投影给加密算子。直接加密路径处理已有应用值，可以绕过预处理。

给定记录序列 $r_0,\ldots,r_{N-1}$，筛选条件 $P_Q$ 决定按原始记录顺序排列的索引序列 $\mathcal I_Q=(i_0,\ldots,i_{M-1})$，投影 $\pi_Q$ 提取每条选中记录的输入值。第 $j$ 个应用值对应的密文为

$$
c_j=\operatorname{Enc}_E\bigl(\operatorname{Encode}_E(\pi_Q(r_{i_j}))\bigr),\quad 0\leq j<M.
$$

这里的 $c_j$ 表示一个应用值对应的密文集合，其中的 LWE 密文数量由编码方式决定。Host 同时保留索引序列与密文序列。对于逐元素更新，第 $j$ 个返回结果对应记录 $i_j$，因此可以恢复筛选前的记录位置，并更新该记录中的目标字段。

任务语义与运行设置分别描述。运行配置指定设备端点、批次大小和传输粒度。Host 将源范围划分为块对齐批次，并保留每批的起始记录编号，使局部索引可以转换为全局记录位置。同一任务根据 $O$ 的设置，可以在密文生成后结束，也可以继续经过远端计算、结果恢复与写回。

## 3.3 算子图与设备执行

一次设备执行由算子程序、算子上下文和输入输出内存范围共同描述。程序指定算子类型及其流连接关系；上下文给出记录布局、筛选条件、投影字段和密码配置等参数；内存范围指定本次执行使用的设备缓冲及字节范围。这三类对象将应用任务中的逻辑操作绑定到实际输入输出数据。

Host 通过 CSD 接口加载并激活程序，再携带上下文和数据范围提交执行请求。Device Runtime 将逻辑算子编号映射到可用的 FPGA 算子实例，并配置流连接和缓冲传输。选择性输入处理将筛选与投影算子直接连接到编码与加密算子，使投影值在 CSD 内部的 FPGA 算子之间流动。直接加密使用单个密码算子。返回路径则执行独立的解密程序，其输入范围容纳返回密文，输出范围接收解码后的应用值。

筛选结果同时决定加密工作量和输出容量。对于每个选择性批次，设备生成的选择元数据向 Host 提供选中数量与记录索引。Host 根据选中数量和每个应用值的密文大小，绑定生成程序的输出范围。选择发现与密文生成读取同一份设备缓冲中的输入图像，使选中数量、密文顺序和记录映射对应相同输入。未选中任何记录的批次跳过加密与远端计算。

## 3.4 密文交接与结果写回

在 CSD 与 Host 的交接处，Host 根据设备返回的有效输出长度和任务中的密码配置构造网络请求。请求包含标识符、密文形状元数据和密文负载。当前原型在把返回批次交给解密路径之前检查响应标识与元数据。输入生成、远端计算和结果恢复需要就编码方式、密码参数与密文序列化表示达成一致。

Host 通过 PCIe 将返回密文放入设备本地输入缓冲，再调用 FPGA 解密与解码算子。恢复的应用值按照任务指定的目标策略写回。对于连续结果，设备将解密输出缓冲复制到指定 SSD 范围。对于选中记录的字段更新，Host 使用保留的索引序列，将恢复值合并到对应记录页，再将记录图像写入目标范围；未选中记录及选中记录的其他字段保持原值。

应用区分密文生成完成、远端响应到达和结果写回完成三个时点。仅生成密文的任务在密文输出与记录映射可用后完成；更新任务还需要等待结果恢复与目标 I/O 完成。任务接口为选中记录的更新指定独立目标范围，原型通过读回并比较记录图像验证写入结果。
